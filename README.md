# DeskMate

macOS 화면 안을 돌아다니는 작은 데스크톱 동료입니다. 기본 캐릭터는 돌멩이이며, 프로젝트 폴더에서 Codex나 Claude Code에 요청해 외형과 어울리는 동작을 함께 수정하는 사용 방식을 목표로 합니다.

현재는 **자유 이동·출퇴근 진행률·보관되는 To Do 메모와 일회성 예약 알림을 지원하는 데스크톱 시제품**입니다. 메모의 지정 시각에 소리 없이 점프와 말풍선으로 알리고, 잠자기·재실행 후 놓친 알림도 복원합니다. AI 대화는 다음 단계이며, 알림 미리보기 버튼으로 동작을 미리 볼 수 있습니다.

GitHub에 소스를 공개하고, 각 사용자가 자신의 Mac에서 의존성을 설치해 직접 빌드·실행하는 방식입니다. 사용자는 같은 프로젝트 폴더에서 AI Agent로 캐릭터와 소스를 수정할 수 있습니다.

## 소스 설치와 실행

개발 환경에는 macOS와 Node.js 22.12.0 이상이 필요합니다. `.nvmrc`는 Node.js 24를 지정합니다. 저장소를 clone한 뒤 실행하세요.

```sh
git clone https://github.com/didxodnr0769-bom/deskmate.git
cd deskmate
npm ci
npm run dev
```

`npm ci`에서 Electron 실행 파일도 내려받습니다. 내려받기가 중단되었다면 `npx --no-install install-electron`으로 다시 받을 수 있습니다. 패키징된 `.app` 실행에는 Node.js가 필요하지 않습니다.

`dev`는 코드를 한 번 빌드한 뒤 Electron을 실행합니다. 코드를 수정했다면 앱을 종료하고 다시 실행하세요.

본인 Mac에서 사용할 `.app`을 만들려면 다음 명령을 실행하세요.

```sh
npm run package:mac
```

생성된 앱은 `release/Desktop Companion-darwin-<아키텍처>/Desktop Companion.app`에 있습니다. 패키징은 실행한 Mac의 CPU 아키텍처를 따릅니다.

프로젝트명은 DeskMate이며, 현재 macOS 앱 이름은 기존 데이터 호환성을 위해 `Desktop Companion.app`을 사용합니다. 소스 ZIP은 `release/deskmate-v<버전>-source.zip`으로 생성되며 최상위 폴더는 `deskmate/`입니다.

## 제공 기능

- 모니터 작업 영역 안에서 가로·세로로 이동하고 경계에서 방향을 바꾸는 돌멩이
- 캐릭터 클릭으로 작은 조작 패널 열기
- 캐릭터를 원하는 위치나 다른 모니터로 드래그하고 놓은 위치에서 이동 이어가기
- 출근일·출근시간·퇴근시간을 입력하고 실제 진행률을 캐릭터 위 HP 게이지로 표시
- 메모 추가·수정·완료·완료 취소·삭제와 선택적인 알림 시간 기록
- 메모 시각의 일회성 무음 알림, 미확인 알림 복원과 확인한 알림의 중복 방지
- `⌘⇧Space`로 캐릭터와 패널 숨기기·다시 표시하기
- 패널에서 자율 이동 켜기·끄기
- 알림 미리보기로 무음 점프와 말풍선 확인하기

캐릭터 외의 투명한 영역은 뒤에 있는 창을 클릭할 수 있게 처리합니다. 단축키가 다른 앱과 겹치면 패널에서 변경할 수 있습니다. 실제 확인 결과와 추가 수동 점검 항목은 [검증 안내](docs/verification.md)를 참고하세요.

메뉴 막대의 돌멩이 아이콘에서도 패널 열기, 숨기기·표시, 알림 미리보기, 종료를 사용할 수 있습니다. Dock 아이콘은 숨겨집니다. 적용한 근무시간과 메모는 앱을 다시 실행해도 유지되며, 이동·단축키 설정은 현재 실행 중에만 적용됩니다.

## 출퇴근시간 입력

캐릭터를 클릭한 뒤 출근일과 출근시간을 입력하세요. 출근시간을 바꾸면 퇴근시간을 기본 +9시간으로 채우며, 이후 퇴근시간을 직접 수정할 수 있습니다. **적용**을 눌러야 계산과 저장에 반영됩니다.

HP는 출근 전과 출근 시각에 0%, 퇴근 시각에 100%가 됩니다. 1초마다 현재 시각으로 다시 계산하고, 중간 비율은 내림 처리합니다. 남은 시간은 퇴근 시각까지의 분을 올림 처리합니다.

퇴근시간이 출근시간보다 이르면 다음날 퇴근으로 계산하며, 같은 시각은 입력할 수 없습니다. 출근일은 자정이나 재실행 때 바뀌지 않습니다. 다른 날의 근무시간을 설정하려면 날짜를 변경해서 적용하세요.

## 메모 사용

캐릭터를 클릭하고 패널의 **메모** 탭을 여세요. 새 메모를 입력한 뒤 **추가**를 누르고, 기존 항목은 **수정** 후 **저장**할 수 있습니다. 체크박스로 완료하거나 완료를 취소하며, 완료한 메모도 보관됩니다. **삭제**를 누르면 확인을 거쳐 처리합니다. 알림 시간은 선택이며 **해제**로 지울 수 있습니다.

메모 내용은 앞뒤 공백을 제외한 1~1,000자이며, 완료한 메모를 포함해 최대 500개를 보관합니다. 알림은 연월일 없이 시간만 입력합니다. 선택한 시간은 `15:00`처럼 `HH:mm` 형식으로 보관하고 목록에도 시간만 표시합니다. 반복 기능은 없습니다.

시간을 새로 지정하면 이 Mac의 로컬 시각을 기준으로 다음에 도래하는 시각에 **한 번** 예약합니다. 현재 분을 선택하면 즉시, 이미 지난 시간이면 다음날에 알립니다. 예를 들어 14:00에 15:00을 저장하면 오늘, 16:00에 15:00을 저장하면 내일입니다. 본문만 수정하면 예약과 확인 상태를 유지합니다. 시간을 변경하거나 해제 후 다시 지정하거나 완료를 취소하면 새로 예약하며, 완료·삭제·시간 해제는 예약을 취소합니다.

알림은 직접 닫을 때까지 유지되며 닫아도 메모가 완료되지는 않습니다. 여러 알림은 예약 시각 순서로 하나씩 표시합니다. 숨긴 캐릭터는 알림 때 잠시 나타나고, 대기 중인 알림을 모두 닫으면 다시 숨겨집니다. 사용자가 패널을 열어 직접 표시한 경우에는 그대로 표시합니다. 알림 중에도 캐릭터를 드래그할 수 있으며 조작이 끝나면 알림 자세로 돌아갑니다.

앱 실행 중에는 약 1초 간격으로 예약을 확인합니다. 앱이 종료된 동안에는 알릴 수 없으며, 잠자기 복귀나 재실행 때 지난 예약을 복구합니다. 닫지 않은 알림은 재실행 후 다시 나타나고, 닫아서 확인 상태가 저장된 알림은 다시 표시하지 않습니다. 확인 상태를 저장하지 못하면 오류와 함께 말풍선을 유지하므로 다시 닫아 주세요. 예약한 순간은 저장되며 이후 Mac의 시간대를 바꾸어도 같은 순간을 유지합니다.

이전 형식의 메모를 읽으면 내용과 완료 상태를 유지하며, v1 알림 일시에서는 이 Mac의 로컬 시간만 가져옵니다. 기존 v1/v2 메모의 미완료 항목은 업그레이드 후 처음 실행한 시점을 기준으로 다음 시각에 예약합니다. 원본을 읽는 것만으로 파일을 바꾸지는 않지만, 앱의 첫 알림 초기화 또는 메모 변경 시 `memos.v1.backup.json` 또는 `memos.v2.backup.json`에 원본을 보관한 뒤 v3로 저장합니다. 기존 백업은 덮어쓰지 않으며 백업이나 저장이 실패하면 예약 전달과 변경을 보류합니다.

메모 파일을 읽거나 검증하지 못하면 원본을 덮어쓰지 않고 메모 탭에 오류를 표시하며 편집을 막습니다. 근무시간과 캐릭터 기능은 별도로 사용할 수 있습니다.

## 개발 명령

| 명령 | 동작 |
| --- | --- |
| `npm run dev` | 타입 검사와 빌드 후 Electron 실행 |
| `npm run build` | 타입 검사 후 `dist/` 생성 |
| `npm run typecheck` | TypeScript 타입 검사 |
| `npm test` | `tests/*.test.ts` 실행 |
| `npm start` | 기존 `dist/`로 Electron 실행 |
| `npm run package:mac` | 빌드 후 `release/`에 macOS 앱과 앱·소스 ZIP 생성 |

공개 범위는 소스 코드이며, 완성된 앱의 다운로드 배포와 Apple 개발자 서명·공증, DMG 설치 패키지는 현재 계획에 포함하지 않습니다. 패키징으로 생성되는 앱과 ZIP은 로컬 사용·개발용 산출물입니다.

## 로컬 데이터와 라이선스

이 저장소를 clone해 수정한 소스는 각자의 개발 환경에서 빌드할 수 있습니다. `.gitignore`는 의존성·빌드·패키징 결과, 로컬 메모와 근무시간, 검증 데이터, 환경 파일과 인증서·키를 제외합니다. 개인 AI 도구 설정과 대화 기록도 공유 소스에 넣지 마세요. 이미 Git에 추가한 파일에는 제외 규칙이 소급 적용되지 않으므로 커밋할 파일 목록을 확인하세요. 캐릭터 코드와 `package-lock.json`은 소스에 포함합니다.

메모와 근무시간은 Electron의 `userData` 폴더에 `memos.json`, `worktime.json`으로 저장됩니다. 이전 메모의 원본 백업은 `memos.v1.backup.json` 또는 `memos.v2.backup.json`입니다. 검증용으로 `COMPANION_DATA_DIR`를 지정하면 그 폴더를 사용하므로 소스 폴더 밖으로 지정하세요. 메모 본문과 근무 기록은 공유 소스에 포함하지 않습니다.

프로젝트 코드는 [MIT 라이선스](LICENSE)로 제공합니다. Electron·Chromium과 기타 의존성에는 각자의 라이선스가 적용됩니다. 패키징 시 앱의 `Contents/Resources/`에 프로젝트 라이선스, [타사 소프트웨어 고지 안내](THIRD_PARTY_NOTICES.md)와 `THIRD_PARTY_NOTICES/`의 원본 고지를 함께 보관합니다.

## 캐릭터 바꾸기

이 프로젝트 폴더에서 AI Agent를 실행하고 다음과 같이 요청할 수 있습니다. 공통 작업 안내는 [AGENTS.md](AGENTS.md), [CLAUDE.md](CLAUDE.md), [Agent 작업 허브](.agents/README.md)에 있습니다.

> `docs/character-guide.md`를 읽고 기본 돌멩이를 통통한 검은 고양이로 바꿔줘. 대기·걷기·잡힘·놓기·알림 동작도 고양이에 어울리게 함께 수정하고, 기존 패널과 드래그 기능은 유지해줘.

캐릭터는 코드로 그립니다. 기본 제공 형태를 수정하는 데 앱 내부 이미지 생성 서비스나 별도 AI API 키를 요구하지 않습니다. Agent가 사용하는 외부 도구의 기능과 비용은 각 사용 환경에 따릅니다.
