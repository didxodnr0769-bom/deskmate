# DeskMate

macOS 화면 안을 돌아다니는 작은 데스크톱 동료입니다. 기본 캐릭터는 돌멩이이며, 프로젝트 폴더에서 Codex나 Claude Code에 요청해 외형과 어울리는 동작을 함께 수정하는 사용 방식을 목표로 합니다.

현재 0.8.0 소스는 **자유 이동·출퇴근 진행률·보관되는 To Do 메모·일회성 및 반복 알림·선택적인 퇴근 전 할 일 요약**을 제공합니다. Codex CLI를 연결하면 전용 대화 창에서 이전 이야기를 이어가고 메모·근무시간 조회와 변경도 요청할 수 있습니다. 캐릭터 말풍선에는 알림과 응답 생성 상태·답변이 표시됩니다.

구현 범위와 실제 환경의 검증 완료 여부는 구분합니다. 버전별 수행 결과와 남은 점검은 [검증 안내](docs/verification.md)를 기준으로 확인하세요.

GitHub에 소스를 공개하고, 각 사용자가 자신의 Mac에서 의존성을 설치해 직접 빌드·실행하는 방식입니다. 사용자는 같은 프로젝트 폴더에서 AI Agent로 캐릭터와 소스를 수정할 수 있습니다.

## 소스 설치와 실행

개발 환경에는 macOS와 Node.js 22.12.0 이상이 필요합니다. `.nvmrc`는 Node.js 24를 지정합니다. 저장소를 clone한 뒤 실행하세요.

```sh
git clone https://github.com/didxodnr0769-bom/deskmate.git
cd deskmate
npm ci
npm run dev
```

`npm ci`에서 Electron 실행 파일도 내려받습니다. 내려받기가 중단되었다면 `npx --no-install install-electron`으로 다시 받을 수 있습니다. 패키징된 `.app` 실행에는 Node.js가 필요하지 않습니다.

`dev`는 코드를 한 번 빌드한 뒤 Electron을 실행합니다. 코드를 수정했다면 앱을 종료하고 다시 실행하세요.

본인 Mac에서 사용할 `.app`을 만들려면 다음 명령을 실행하세요.

```sh
npm run package:mac
```

생성된 앱은 `release/Desktop Companion-darwin-<아키텍처>/Desktop Companion.app`에 있습니다. 패키징은 실행한 Mac의 CPU 아키텍처를 따릅니다.

프로젝트명은 DeskMate이며, 현재 macOS 앱 이름은 기존 데이터 호환성을 위해 `Desktop Companion.app`을 사용합니다. 소스 ZIP은 `release/deskmate-v<버전>-source.zip`으로 생성되며 최상위 폴더는 `deskmate/`입니다.

## 제공 기능

- 모니터 작업 영역 안에서 가로·세로로 이동하고 경계에서 방향을 바꾸는 돌멩이
- 캐릭터 좌클릭으로 대화 창 열기, 우클릭 메뉴에서 대화·근무시간·메모로 바로 이동
- 캐릭터를 원하는 위치나 다른 모니터로 드래그하고 놓은 위치에서 이동 이어가기
- 출근일·출근시간·퇴근시간을 입력하고 실제 진행률을 캐릭터 위 HP 게이지로 표시, 비율에 따라 빨강·주황·노랑·초록·진한 초록으로 전환
- 메모 추가·수정·완료·완료 취소·삭제와 알림 방식 선택
- 지정 시각 한 번·몇 분 뒤·매일·요일별 무음 알림, 미확인 알림 복원
- 기본으로 꺼진 퇴근 전 할 일 요약과 5~120분 전 알림 설정
- `⌘⇧Space`로 캐릭터와 패널 숨기기·다시 표시하기
- 패널에서 자율 이동 켜기·끄기
- 알림 미리보기로 무음 점프와 말풍선 확인하기
- Codex CLI를 통한 이어지는 대화와 이력 표시, 새 대화, 연결 상태 확인과 요청 취소
- 대화로 메모 조회·추가·수정·완료·완료 취소, 근무시간 조회·변경, 자율 이동·화면 열기, 요약·퇴근 전 알림 설정
- `⌘⇧Enter`로 여는 대화 전용 창과 말풍선의 응답 생성 중 표시

캐릭터 외의 투명한 영역은 뒤에 있는 창을 클릭할 수 있게 처리합니다. 단축키가 다른 앱과 겹치면 숨기기는 근무 패널에서, 대화는 대화 창의 설정에서 변경할 수 있습니다. 실제 확인 결과와 추가 수동 점검 항목은 [검증 안내](docs/verification.md)를 참고하세요.

메뉴 막대의 돌멩이 아이콘에서도 대화하기, 패널 열기, 숨기기·표시, 알림 미리보기, 종료를 사용할 수 있습니다. Dock 아이콘은 숨겨집니다. 적용한 근무시간과 메모는 앱을 다시 실행해도 유지되며, 이동·단축키 설정은 현재 실행 중에만 적용됩니다.

## 출퇴근시간 입력

캐릭터를 우클릭하고 **근무시간**을 선택한 뒤 출근일과 출근시간을 입력하세요. macOS의 Control+클릭이나 트랙패드 보조 클릭도 사용할 수 있습니다. 출근시간을 바꾸면 퇴근시간을 기본 +9시간으로 채우며, 이후 퇴근시간을 직접 수정할 수 있습니다. **적용**을 눌러야 계산과 저장에 반영됩니다.

HP는 출근 전과 출근 시각에 0%, 퇴근 시각에 100%가 됩니다. 1초마다 현재 시각으로 다시 계산하고, 중간 비율은 내림 처리합니다. 남은 시간은 퇴근 시각까지의 분을 올림 처리합니다.

퇴근시간이 출근시간보다 이르면 다음날 퇴근으로 계산하며, 같은 시각은 입력할 수 없습니다. 출근일은 자정이나 재실행 때 바뀌지 않습니다. 다른 날의 근무시간을 설정하려면 날짜를 변경해서 적용하세요.

## 메모 사용

캐릭터를 우클릭하고 **메모**를 선택하세요. 열린 관리 패널에서는 근무·메모 탭으로 전환할 수 있습니다. 새 메모를 입력한 뒤 **추가**를 누르고, 기존 항목은 **수정** 후 **저장**할 수 있습니다. 체크박스로 완료하거나 완료를 취소하며, 완료한 메모도 보관됩니다. **삭제**를 누르면 확인을 거쳐 처리합니다. 알림 시간은 선택이며 **해제**로 지울 수 있습니다.

메모 내용은 앞뒤 공백을 제외한 1~1,000자이며, 완료한 메모를 포함해 최대 500개를 보관합니다. **알림 방식**에서 다음 중 하나를 선택합니다. 메모에 연월일을 직접 입력하는 방식은 아닙니다.

| 방식 | 동작 |
| --- | --- |
| 알림 없음 | 예약하지 않음 |
| 시각 한 번 | 다음에 도래하는 로컬 시각에 한 번 |
| 몇 분 뒤 | 저장한 순간부터 지정한 분 뒤에 한 번 |
| 매일 | 매일 선택한 로컬 시각 |
| 요일 반복 | 선택한 요일의 로컬 시각 |

시각은 `15:00`처럼 `HH:mm` 형식입니다. **시각 한 번**은 현재 분을 선택하면 즉시, 이미 지난 시간이면 다음날 알립니다. **몇 분 뒤**로 저장한 메모를 수정할 때는 예약 일시를 보여주며, 내용만 수정하면 그 시각을 유지합니다. **다시 예약**을 선택하면 저장할 때 새로 계산합니다.

본문만 수정하면 기존 일정과 확인 상태를 유지합니다. 알림 방식·시간·요일을 바꾸면 재예약하고, 완료·삭제·알림 해제는 예약을 취소합니다. 완료 취소는 설정된 일정으로 예약을 다시 활성화합니다. 완료한 메모도 보관합니다.

알림은 직접 닫을 때까지 유지되며, 닫아도 메모가 완료되지는 않습니다. 일회성 알림은 확인한 뒤 다시 표시하지 않습니다. 반복 알림은 닫기 확인을 저장하면서 **현재보다 뒤의 다음 회차**를 예약합니다. 여러 회차를 놓쳤어도 메모 하나마다 미확인 알림 하나를 복원하며, 지난 회차를 연달아 쌓아 보여주지 않습니다.

여러 메모 알림은 예약 시각 순서로 하나씩 표시합니다. 숨긴 캐릭터는 알림 때 잠시 나타나고, 대기 알림을 모두 닫으면 다시 숨겨집니다. 사용자가 관리 패널을 열어 직접 표시한 경우에는 그대로 표시합니다. 알림 중에도 캐릭터를 드래그할 수 있습니다. 메모 알림 말풍선을 누르면 메모 탭을 열며, 이 동작은 알림 확인이나 메모 완료를 뜻하지 않습니다.

앱 실행 중에는 약 1초 간격으로 예약을 확인하고, 잠자기 복귀·재실행 때 미확인 예약을 복구합니다. 앱이 종료된 동안에는 알릴 수 없습니다. 확인 상태를 저장하지 못하면 오류와 함께 말풍선을 유지하므로 다시 닫아 주세요. 한 번 예약한 순간은 보존하며, 반복 일정의 다음 회차는 확인 시점의 로컬 달력을 기준으로 계산합니다.

메모 저장 형식은 v4입니다. v1/v2/v3를 읽으면 내용을 유지하고, 첫 알림 초기화 또는 변경 때 원본을 `memos.v1.backup.json`, `memos.v2.backup.json`, `memos.v3.backup.json` 중 해당 파일에 보관한 뒤 v4로 교체합니다. 기존 백업은 덮어쓰지 않습니다. v1/v2는 다음 로컬 시각에 한 번 예약하고, v3의 기존 예약·확인 상태는 유지합니다. 백업이나 저장이 실패하면 원본과 메모리 상태를 유지합니다.

메모 파일을 읽거나 검증하지 못하면 원본을 덮어쓰지 않고 메모 탭에 오류를 표시하며 편집을 막습니다. 근무시간과 캐릭터 기능은 별도로 사용할 수 있습니다.

## 퇴근 전 할 일 요약

캐릭터 우클릭 → **근무시간**의 **퇴근 전 할 일 알림**에서 켜고, 퇴근 몇 분 전인지 지정한 뒤 **저장**하세요. 기본은 꺼짐이며 기본 시점은 30분 전입니다. 5~120분 사이의 정수로 설정할 수 있습니다.

적용한 근무시간의 알림 구간에 남은 메모가 있으면 개수와 최대 5개 항목을 말풍선으로 보여줍니다. 이 요약은 앱이 로컬 데이터로 계산하므로 AI 연결이 필요하지 않습니다. 말풍선을 누르면 메모 목록을 엽니다. 닫기 확인을 저장한 근무 일정에서는 재실행해도 반복하지 않습니다. 퇴근 이후에 지난 요약을 새로 띄우지 않으며, 설정·확인 상태는 재실행 후에도 유지합니다.

## 앱에서 AI에게 질문하기

AI 대화는 선택 기능입니다. 메모·근무시간·캐릭터는 Codex 없이도 사용할 수 있습니다.

1. [공식 안내](https://developers.openai.com/codex/cli)에 따라 Codex CLI를 설치하세요. 현재 검증한 버전은 `0.154.0`이며 이 버전 이상이 필요합니다.
2. 터미널에서 `codex login`으로 로그인하세요. 앱이 인증 파일이나 API 키를 따로 복사·저장하지 않습니다.
3. 캐릭터를 좌클릭하거나 **⌘⇧Enter**, 우클릭 메뉴·메뉴 막대의 **대화하기**로 대화 창을 열어 연결 상태를 확인하세요. 질문을 입력하고 **Enter** 또는 **보내기**로 전송하며 **Shift+Enter**로 줄을 바꿉니다.
4. 답변을 기다리는 동안 **취소**할 수 있습니다. 로그인이나 실행 문제가 생기면 안내를 확인한 뒤 **다시 확인**하세요.

질문은 최대 4,000자입니다. **새 대화**를 누르기 전까지 이 창의 질문·답변을 함께 전달하며, 사용자도 이력을 스크롤해 볼 수 있습니다. 취소·실패한 질문은 상태와 함께 남습니다. 대화 창을 닫거나 **Esc**를 눌러도 이력·작성 중인 입력·진행 요청은 유지됩니다. **새 대화**는 진행 요청을 취소하고 이력과 맥락을 함께 초기화합니다. 대화는 실행 중 메모리에만 보관하므로 앱을 종료하면 사라집니다. 메모·근무시간 파일 전체를 자동 제공하지 않지만, 사용자가 요청한 조회 결과는 답변 이력에 남아 후속 질문에 전달됩니다.

질문을 보내면 돌멩이 말풍선에 **응답 생성 중…**이 표시됩니다. 말풍선의 X는 표시만 접고, **취소**는 요청을 종료합니다. 완료된 답변은 대화 창과 말풍선에 일반 텍스트로 표시합니다. 예약 메모 알림이 우선하며 알림을 닫으면 현재 생성 상태 또는 완료 답변을 표시합니다. 대화가 너무 길어지면 이전 이력을 몰래 자르지 않고 새 대화를 안내합니다.

AI 답변과 생성 중 말풍선을 클릭하면 진행 중인 대화 창을 엽니다. 말풍선의 제목도 진입 버튼이며, X·취소·텍스트 선택·스크롤과는 구분합니다. 메모 알림 말풍선은 메모 탭을 열고 알림이나 메모를 자동 확인·완료 처리하지 않습니다. 캐릭터 드래그는 기존 위치 이동을 유지하며 우클릭 메뉴가 열린 동안에는 이동을 잠시 멈춥니다.

관리 패널은 근무·메모용입니다. 대화 단축키는 대화 창 상단 **설정**에서 변경하며 숨기기와 같은 조합으로 등록할 수 없습니다. 설정을 펼쳐도 대화 이력과 작성 중인 질문은 유지됩니다.

앱은 기존 CLI 로그인을 사용합니다. CLI 실행 파일은 PATH, Homebrew, `~/.local/bin`, nvm 설치 경로에서 찾습니다. 자동으로 찾지 못하면 앱을 실행하는 환경에 `DESKMATE_CODEX_PATH`를 Codex 실행 파일의 절대경로로 지정할 수 있습니다. 실행 경로나 개인 환경 설정은 저장소에 넣지 마세요.

기본 연결은 CLI 기본 모델을 사용합니다. 다음과 같이 앱 기능도 요청할 수 있습니다.

- “메모 목록 보여줘”, “완료한 메모 찾아줘”
- “10분 뒤에 물 마시라고 알려줘”, “매일 오후 3시에 스트레칭 알려줘”
- “매주 월요일과 수요일 오전 10시에 회의 준비 알려줘”
- “회의 준비 메모를 완료해줘”, “그 메모 완료를 취소해줘”
- “등록된 근무시간 알려줘”, “퇴근시간을 오후 7시로 바꿔줘”
- “자유 이동 멈춰줘”, “메모 화면 열어줘”, “남은 할 일과 근무 현황 요약해줘”
- “퇴근 30분 전 남은 할 일 알림 켜줘”

변경할 메모가 여러 개면 후보를 보여주고 번호로 선택하게 합니다. 같은 내용의 메모를 임의로 고르지 않으며, 후보를 보여준 뒤 항목이 변경되면 다시 요청하도록 안내합니다. “3시”처럼 오전·오후가 불분명한 요청은 먼저 확인합니다. 삭제는 메모 관리 패널에서 확인 후 수행합니다.

AI는 허용된 앱 명령을 JSON으로 제안합니다. main의 서비스가 명령 종류·대상·값을 검증하고 기존 저장 기능을 호출한 뒤 성공 결과를 만듭니다. 저장 실패를 완료로 안내하지 않으며, 자유 형식 답변을 코드로 실행하지 않습니다.

메모·근무시간 파일 전체는 일반 대화에 자동 제공하지 않습니다. 다만 사용자가 요청한 메모 조회·근무 현황·요약과 실행 결과는 답변으로 대화 이력에 남으므로, **새 대화** 전까지 후속 질문에도 함께 전달됩니다. 조회한 내용을 다음 대화에 남기지 않으려면 **새 대화**를 시작하세요.

실시간 검색과 로컬 파일 작업은 제공하지 않습니다. 질문 실행 시 앱 전용 대화 지침으로 기본 코딩 역할을 교체하고, 실제 대화 이력과 현재 질문을 구분해 전달합니다. 개인 CLI 설정과 세션 저장을 사용하지 않으며, 빈 임시 작업 폴더·읽기 전용 권한·도구 비활성화 옵션을 적용합니다. 응답 제한 시간은 120초이며, 취소·시간 초과 때 실행 프로세스를 종료합니다. CLI의 인증 캐시와 자체 운영 기록은 CLI가 관리합니다. 자세한 실행 방식은 [AI 연결 안내](docs/agent-provider-guide.md)를 참고하세요.

## 개발 명령

| 명령 | 동작 |
| --- | --- |
| `npm run dev` | 타입 검사와 빌드 후 Electron 실행 |
| `npm run build` | 타입 검사 후 `dist/` 생성 |
| `npm run typecheck` | TypeScript 타입 검사 |
| `npm test` | `tests/*.test.ts` 실행 |
| `npm start` | 기존 `dist/`로 Electron 실행 |
| `npm run package:mac` | 빌드 후 `release/`에 macOS 앱과 앱·소스 ZIP 생성 |

공개 범위는 소스 코드이며, 완성된 앱의 다운로드 배포와 Apple 개발자 서명·공증, DMG 설치 패키지는 현재 계획에 포함하지 않습니다. 패키징으로 생성되는 앱과 ZIP은 로컬 사용·개발용 산출물입니다.

## 로컬 데이터와 라이선스

이 저장소를 clone해 수정한 소스는 각자의 개발 환경에서 빌드할 수 있습니다. `.gitignore`는 의존성·빌드·패키징 결과, 로컬 메모와 근무시간, 검증 데이터, 환경 파일과 인증서·키를 제외합니다. 개인 AI 도구 설정과 대화 기록도 공유 소스에 넣지 마세요. 이미 Git에 추가한 파일에는 제외 규칙이 소급 적용되지 않으므로 커밋할 파일 목록을 확인하세요. 캐릭터 코드와 `package-lock.json`은 소스에 포함합니다.

메모와 근무시간은 Electron의 `userData` 폴더에 `memos.json`, `worktime.json`으로 저장됩니다. 퇴근 전 알림 설정과 확인 상태는 `briefing.json`에 따로 저장됩니다. 이전 메모의 원본 백업은 `memos.v1.backup.json`, `memos.v2.backup.json`, `memos.v3.backup.json`입니다. 검증용으로 `COMPANION_DATA_DIR`를 지정하면 그 폴더를 사용하므로 소스 폴더 밖으로 지정하세요. 메모 본문과 근무 기록은 공유 소스에 포함하지 않습니다.

프로젝트 코드는 [MIT 라이선스](LICENSE)로 제공합니다. Electron·Chromium과 기타 의존성에는 각자의 라이선스가 적용됩니다. 패키징 시 앱의 `Contents/Resources/`에 프로젝트 라이선스, [타사 소프트웨어 고지 안내](THIRD_PARTY_NOTICES.md)와 `THIRD_PARTY_NOTICES/`의 원본 고지를 함께 보관합니다.

## 캐릭터 바꾸기

이 프로젝트 폴더에서 AI Agent를 실행하고 다음과 같이 요청할 수 있습니다. 공통 작업 안내는 [AGENTS.md](AGENTS.md), [CLAUDE.md](CLAUDE.md), [Agent 작업 허브](.agents/README.md)에 있습니다.

> `docs/character-guide.md`를 읽고 기본 돌멩이를 통통한 검은 고양이로 바꿔줘. 대기·걷기·잡힘·놓기·알림 동작도 고양이에 어울리게 함께 수정하고, 기존 패널과 드래그 기능은 유지해줘.

캐릭터는 코드로 그립니다. 기본 제공 형태를 수정하는 데 앱 내부 이미지 생성 서비스나 별도 AI API 키를 요구하지 않습니다. Agent가 사용하는 외부 도구의 기능과 비용은 각 사용 환경에 따릅니다.
