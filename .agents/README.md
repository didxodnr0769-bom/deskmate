# DeskMate Agent 작업 허브

공유 문서의 기준은 `README.md`와 `docs/`입니다. 이 허브에 기능 명세를 중복 관리하지 않습니다.

- `docs/architecture.md`: 현재 구현과 후속 기능의 경계
- `docs/character-guide.md`: 캐릭터 수정 위치와 보존할 계약
- `docs/agent-provider-guide.md`: 앱 내 AI 대화 연결의 책임 분리
- `docs/verification.md`: 점검 명령, 검증 수준과 남은 수동 점검

기본 캐릭터는 Canvas 2D로 그린 돌멩이입니다. 캐릭터를 변경할 때 외형, 대기·걷기·잡힘·놓기·알림 동작과 클릭 윤곽을 함께 조정하세요. 앱 내부 이미지 생성 서비스나 AI API 키가 필요한 구조는 아닙니다.

캐릭터는 화면 안을 X·Y 방향으로 이동하며 드롭한 위치와 높이를 유지합니다. 바닥 고정·바닥 복귀나 화면 선택기·HP 수동 슬라이더를 다시 추가하지 마세요. HP는 적용한 출근일·출근·퇴근시간으로 main에서 계산하고 저장합니다.

메모는 To Do와 선택적인 시각 한 번·몇 분 뒤·매일·요일 반복 알림을 입력받습니다. 완료 항목도 보관하며 근무시간 파일과 분리합니다. 저장 형식은 v4이며 v1/v2/v3 원본은 버전별 백업 후 옮깁니다. 명시한 같은 일정의 본문 수정은 원 예약을 유지하고, 반복 확인은 누락 회차를 한꺼번에 만들지 않고 다음 미래 회차를 예약합니다. 세부 기준은 `docs/architecture.md`와 검증 안내를 따르세요.

창 이동은 `nativePosition` 검증을 거친 `moveWidget`을 사용합니다. Electron에 음수 0, 비유한값이나 int32 범위 밖 좌표를 전달하지 마세요.

수동 알림 미리보기와 실제 일회성 메모 알림을 구분하세요. AI로 소스를 커스터마이징할 수 있고, 앱의 전용 대화 창은 Provider 공통 계약을 통해 현재 질문과 새 대화 이후의 이력을 Codex CLI에 보냅니다. 질문·답변 이력은 새 대화 또는 앱 종료까지 메모리에만 둡니다. 일반 대화에 메모·근무시간을 자동 전달하지 않으며, 사용자가 요청한 조회·변경 결과는 보이는 대화 이력에 포함되어 후속 전달됩니다. 예약 알림을 AI 답변보다 우선하고, 취소·종료한 요청의 늦은 응답을 표시하지 마세요. CLI 인자·실행 파일·출력 형식은 Codex 어댑터 안에 유지하세요. 구현 여부와 검증 수준은 소스와 공식 문서에서 확인하세요.

생성 중 말풍선은 실제 진행률을 꾸미지 않습니다. 접기는 표시만 숨기고 취소는 요청을 종료합니다. 새 대화는 이전 요청의 늦은 결과와 대기 말풍선까지 초기화하세요. UI의 AI 요청은 대화 창, 직접 업무 변경은 관리 패널, 말풍선 진입·닫기·현재 요청 취소는 캐릭터 창의 신뢰된 main frame으로 제한합니다. Provider는 허용된 JSON 명령 한 개만 제안하며 main의 AppCommandService가 검증·대상 확인·도메인 저장을 수행한 결과만 답합니다. 취소·새 대화·종료 후 늦은 명령을 실행하지 마세요. 퇴근 전 정리는 기본 꺼짐이며 설정·확인 상태는 briefing.json에 별도 저장합니다. 앱 내 Agent 선택 UI는 제공하지 않고 공통 계약과 교체 가이드로 각자의 Agent를 통해 소스를 수정하게 합니다. 개발 지침과 개인 설정을 사용자의 대화 이력으로 취급하거나 응답에 덧붙이지 마세요.
