# DeskMate Agent 작업 허브

공유 문서의 기준은 `README.md`와 `docs/`입니다. 이 허브에 기능 명세를 중복 관리하지 않습니다.

- `docs/architecture.md`: 현재 구현과 후속 기능의 경계
- `docs/character-guide.md`: 캐릭터 수정 위치와 보존할 계약
- `docs/agent-provider-guide.md`: 향후 앱 내 AI 대화 연결의 책임 분리
- `docs/verification.md`: 점검 명령, 검증 수준과 남은 수동 점검

기본 캐릭터는 Canvas 2D로 그린 돌멩이입니다. 캐릭터를 변경할 때 외형, 대기·걷기·잡힘·놓기·알림 동작과 클릭 윤곽을 함께 조정하세요. 앱 내부 이미지 생성 서비스나 AI API 키가 필요한 구조는 아닙니다.

캐릭터는 화면 안을 X·Y 방향으로 이동하며 드롭한 위치와 높이를 유지합니다. 바닥 고정·바닥 복귀나 화면 선택기·HP 수동 슬라이더를 다시 추가하지 마세요. HP는 적용한 출근일·출근·퇴근시간으로 main에서 계산하고 저장합니다.

메모는 날짜 없는 To Do와 선택 시간(`HH:mm`)을 입력받습니다. 완료 항목도 보관하며 근무시간 파일과 분리합니다. 저장 형식은 v3이며, 이전 형식은 원본 백업 후 예약을 초기화합니다. 예약·확인·재실행 복원 기준은 `docs/architecture.md`의 일회성 알림 절을 따르세요. 메모 입력에 연월일이나 반복 규칙을 임의로 추가하지 마세요.

창 이동은 `nativePosition` 검증을 거친 `moveWidget`을 사용합니다. Electron에 음수 0, 비유한값이나 int32 범위 밖 좌표를 전달하지 마세요.

수동 알림 미리보기와 실제 일회성 메모 알림을 구분하세요. AI로 소스를 커스터마이징하는 흐름은 지원하지만 앱 안의 AI 대화·CLI 실행은 아직 없습니다. 구현 여부와 검증 수준은 소스와 공식 문서에서 확인하세요.
