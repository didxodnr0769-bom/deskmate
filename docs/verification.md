# 검증 안내

현재 버전은 v0.4.1입니다. 이 문서는 실행할 검증 명령, 확인한 기능 범위와 남은 수동 점검을 구분합니다. 이전 버전에서 확인한 동작을 최신 버전의 전체 재검증으로 취급하지 않습니다.

## 검증 명령

macOS의 프로젝트 루트에서 실행합니다.

```sh
npm run typecheck
TZ=Asia/Seoul npm test
TZ=America/New_York npm test
npm run build
npm run package:mac
```

앱은 Mac의 로컬 시각을 사용합니다. 한국 시간대 테스트와 함께 뉴욕 시간대 테스트를 실행하면 서머타임 전환도 확인할 수 있습니다. 테스트 명령의 `TZ`는 해당 프로세스의 시간대를 지정하며 Mac의 시간대 설정을 바꾸지 않습니다.

## 소스 설치와 패키징

- [x] 소스 ZIP의 최상위 폴더 `deskmate/`와 공유 파일 43개의 원본 일치 확인
- [x] 소스 ZIP에 의존성·빌드 산출물·로컬 도구 설정·앱 데이터가 포함되지 않음
- [x] 소스 ZIP과 macOS 앱 ZIP의 압축 무결성 검사 통과
- [x] 패키지와 lock 파일의 이름·버전 일치, 로컬 문서 링크 대상 존재
- [x] 패키징한 앱의 이름 `Desktop Companion`, 번들 ID `land.desktopcompanion.prototype`, 버전 `0.4.1` 유지

이 검증은 소스 설치와 패키징 범위입니다. 설치된 사용자 앱의 데이터 이전이나 최신 패키지의 전체 수동 조작을 확인한 결과는 아닙니다.

## Electron 런타임과 화면

### v0.4.0 예약 알림

2026-10-20, 생성한 앱 ASAR의 main·preload·renderer를 Electron 44.8.0에서 실행해 확인했습니다. 별도 검증 데이터를 사용했습니다.

- [x] 실제 타이머에서 예약 도래 전 말풍선 없음, 도래 후 자동 표시
- [x] 숨김 중 알림 표시, 마지막 알림을 닫은 뒤 네이티브 창 숨김 복귀와 확인 상태 저장
- [x] 현재 분의 메모 두 개를 순차 표시하고 이전 말풍선 ID의 닫기 요청 무시
- [x] 미확인 알림을 남기고 종료·재실행한 뒤 해당 알림만 복원, 확인한 다른 알림은 복원되지 않음
- [x] 네이티브 마우스 이벤트로 메모 탭 선택·말풍선 닫기, 닫은 뒤 재표시 없음과 v3 확인 상태 저장
- [x] 말풍선·HP·캐릭터 표시, 360×510 메모 패널의 편집 폼·하단 버튼과 목록 내부 스크롤
- [x] 메모 탭의 날짜 입력 0개·시간 입력 1개, 문서 가로 넘침 없음
- [x] 확인 저장 실패를 주입했을 때 오류·말풍선 유지, 닫기 재시도 후 저장 성공
- [x] 검증 중 렌더러 오류·비정상 종료 없음

창을 직접 대상으로 한 네이티브 입력으로 확인했습니다. 뒤쪽 앱으로의 클릭 전달이나 물리 키보드 단축키 점검과는 구분합니다.

### v0.4.1 말풍선 배치

말풍선의 아래쪽을 HP 라벨 위에 맞추고, Canvas의 `pose.y`를 CSS 변수로 전달해 캐릭터 점프와 함께 움직이도록 변경했습니다. 클릭 영역은 `getBoundingClientRect()`로 이동한 말풍선의 실제 위치를 사용합니다.

- [x] 실제 macOS 화면에서 미확인 알림 복원, 짧은 말풍선이 HP 바로 위에 표시되고 본체·HP·닫기 버튼이 가려지지 않음
- [x] 현재 돌멩이의 다섯 동작을 0~2000ms에서 1ms 간격으로 정적 계산한 10,005개 표본: 높이 114px의 말풍선 상단 최솟값 1px, 꼬리와 HP 라벨의 최소 여유 약 8.7px
- [x] 본문과 저장 오류가 단일 문단의 65px 높이 제한을 함께 사용하는 소스 확인

긴 메모와 점프 최고점은 정적 계산으로 확인했습니다. 모든 동작의 수동 화면 점검을 뜻하지 않습니다.
