# 검증 안내

현재 버전은 v0.12.0입니다. 이 문서는 실행할 검증 명령, 확인한 기능 범위와 남은 수동 점검을 구분합니다. 이전 버전에서 확인한 동작을 최신 버전의 전체 재검증으로 취급하지 않습니다.

## 검증 명령

macOS의 프로젝트 루트에서 실행합니다.

```sh
npm run typecheck
TZ=Asia/Seoul npm test
TZ=America/New_York npm test
npm run build
npm run package:mac
```

앱은 Mac의 로컬 시각을 사용합니다. 한국 시간대 테스트와 함께 뉴욕 시간대 테스트를 실행하면 서머타임 전환도 확인할 수 있습니다. 테스트 명령의 `TZ`는 해당 프로세스의 시간대를 지정하며 Mac의 시간대 설정을 바꾸지 않습니다.

## 남은 수동 점검

아래 실제 사용 환경 점검은 이번 AI 대화 개선 작업에서 추가로 수행하지 않았습니다.

- [ ] 실제 macOS 잠자기·깨우기를 수행한 예약 알림 복구
- [ ] 실제 키보드·마우스로 새 시간 입력·변경·드래그·알림 닫기를 이어서 수행하는 전체 흐름
- [ ] 다른 앱 사용 중 물리 키보드 전역 단축키로 숨기기·다시 표시
- [ ] 투명 영역은 뒤쪽 앱에 클릭 전달, 캐릭터 본체는 클릭 차단
- [ ] 숨김 상태의 수동 알림 미리보기를 닫은 뒤 숨김 복귀
- [ ] 실제 화면 사방 경계에서 장시간 자율 이동과 방향 전환
- [ ] 화면 배율 차이, 모니터 분리, Dock 위치 변경, 전체 화면 Spaces
- [ ] 장시간 실행의 CPU·메모리·전력 사용량

잠자기 복귀 콜백의 통합 테스트는 실제 잠자기 점검을 대신하지 않습니다. 전역 단축키 등록 성공은 물리 키보드 입력 검증을 뜻하지 않습니다. 근무시간의 자정 경계는 자동 테스트로 확인했으며 실제 자정을 기다리는 점검은 하지 않았습니다.

앱 내부 Provider 선택 UI는 제공하지 않습니다. 공통 계약과 개인 Agent를 통한 소스 교체 안내를 제공합니다. 대화의 앱 종료 후 장기 보관, Apple 개발자 서명·공증과 DMG는 현재 제공 범위에 포함하지 않습니다.
