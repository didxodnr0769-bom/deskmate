# AI Agent 연결 확장 계획

현재 AI 대화·CLI 실행·provider 인터페이스는 구현하지 않았습니다. 근무시간과 메모 기능은 AI 연결 없이 동작하며, 이 문서는 후속 AI 연결의 설계 경계를 설명합니다.

## 두 가지 AI 사용 흐름

1. **프로젝트 수정:** 사용자가 프로젝트 폴더에서 Codex·Claude Code 등을 실행해 캐릭터나 소스를 직접 수정합니다. 현재도 이용할 수 있는 개발 방식이며, [캐릭터 제작 가이드](character-guide.md)를 따릅니다.
2. **앱에서 질문:** 앱의 입력창에서 질문하면 Agent가 답변하고 캐릭터 말풍선에 표시하는 기능입니다. Codex CLI를 첫 대상으로 후속 구현합니다.

프로젝트를 수정하는 Agent와 앱이 대화에 연결하는 Agent는 서로 다른 책임입니다. 캐릭터를 수정하기 위해 앱에 AI API 키를 저장할 필요는 없습니다.

## 후속 구현의 책임 분리

```text
대화 UI
  → 공통 질문·응답 형식
    → Provider 선택
      → Codex 실행 어댑터
      → 다른 Agent 실행 어댑터
```

공통 형식은 질문, 선택적인 취소 신호, 정상 응답과 오류를 다룹니다. 실행 어댑터는 Agent 실행 파일 탐색, 인증 상태 확인, 입력 전달, 출력 변환, 종료·취소·시간 제한을 담당합니다.

다른 Agent로 교체할 때는 어댑터와 선택 설정을 중심으로 수정할 수 있어야 합니다. UI나 근무시간·메모 모듈이 `codex` 명령, CLI별 플래그, 출력 JSON에 직접 의존하게 만들지 않습니다.

구체적인 CLI 플래그와 출력 형식은 구현 시 설치된 CLI와 공식 문서를 확인해 결정합니다. 아직 검증하지 않은 실행 예제를 완성된 연결 코드처럼 제공하지 않습니다.

## 첫 연결에서 다룰 범위

- 사용자가 입력한 질문에 응답하고 말풍선으로 표시
- 실행 중 표시, 취소, 실패·인증 필요 상태 안내
- Agent 연결이 없어도 기존 캐릭터·근무·메모 기능은 독립적으로 사용 가능
- 이전 대화를 장기간 저장하는 기능은 필수 범위에서 제외

날씨 같은 최신 정보는 연결된 Agent가 실제로 조회할 수 있는지 별도 확인해야 합니다. 앱이 검색·날씨 서비스를 직접 제공하는 것으로 가정하지 않습니다.

## 앱 기능 조작 확장

후속 단계에서 “3시 회의 추가해줘” 같은 요청을 다룰 때는 답변 텍스트와 앱 명령을 구분합니다. 공통 업무 기능이 입력값을 검증하고 실행하며, Agent의 자유 형식 답변을 바로 명령으로 실행하지 않습니다.

메모·근무 데이터의 저장 주체는 앱입니다. Agent 교체나 대화 초기화가 업무 데이터 변경으로 이어지지 않아야 합니다. 임의 파일 접근·터미널 명령 실행 범위는 아직 정하지 않았습니다.

근무시간을 조회·변경하는 대화 기능을 추가할 때는 기존 `src/main/domain/worktime.ts`의 검증·계산과 `src/main/domain/worktime-store.ts`의 저장 책임을 재사용합니다. Agent별 실행 어댑터가 저장 파일을 직접 수정하지 않게 합니다.

메모를 조작하는 대화 기능도 `src/main/features/memos.ts`의 `MemoService`를 재사용합니다. 메모 추가·수정에서는 본문과 날짜 없는 선택적인 `reminderTime`(`HH:mm` 문자열 또는 `null`)을 입력받고, main이 ID와 생성·수정 시각을 관리하며 저장에 성공한 뒤 상태를 반영합니다. 향후 Agent 명령도 동일한 검증·보관 경계를 거치게 합니다. `memos.json`을 어댑터가 직접 읽고 수정하는 방식은 피합니다.

메모 파일의 현재 형식은 `version: 3`이며 예약 순간과 확인 상태는 main 내부에서 관리합니다. 이전 형식의 시간 추출·원본 백업·예약 초기화는 `MemoService`가 담당합니다. Agent 연결 코드가 이를 중복 구현하지 않게 합니다.

메모의 일회성 예약 알림과 미확인 알림 복구는 구현돼 있습니다. 시간 변경·완료·완료 취소에 따른 예약 변경도 `MemoService`를 거쳐야 합니다. 대화로 메모를 조작하는 기능은 후속 범위입니다.
