# 보안과 데이터 처리

이 문서는 소스 공개 시 확인할 경계와 알려진 검증 한계를 설명합니다. 사용법은 [사용 안내](usage.md), 이미지 권리 범위는 [이미지 안내](assets.md)를 참고하세요.

## 앱의 경계

- Electron renderer는 Node.js를 직접 사용하지 않으며 contextIsolation과 sandbox를 사용합니다.
- preload가 제한된 API를 제공하고 main은 호출한 창과 main frame을 확인합니다. 외부 탐색·새 창과 외부 스크립트 실행은 차단합니다.
- AI 응답은 일반 텍스트 또는 허용된 JSON 명령 제안입니다. 실제 메모·근무 변경은 main의 검증과 저장 서비스를 거칩니다. 취소·새 대화·종료 뒤 늦은 제안은 실행하지 않습니다.
- 기본 Codex 연결은 도구를 비활성화한 읽기 전용 실행, 앱 전용 지침·임시 작업 폴더와 기존 CLI 로그인을 사용합니다. 앱이 인증 파일이나 키를 복사해 저장하지 않습니다.

## 사용자 데이터

메모·근무시간·캐릭터 설정은 암호화하지 않은 로컬 JSON으로 userData에 저장합니다. 일반 대화에는 파일 전체를 자동으로 보내지 않으며, 사용자가 요청한 조회 결과는 보이는 대화 이력에 포함되어 이후 질문에 전달됩니다. 대화 이력은 새 대화 또는 앱 종료 시 초기화됩니다. CLI 제공자의 자체 데이터 처리 정책은 별도로 적용됩니다.

공유 소스와 소스 ZIP에는 개인 설정·인증·메모 데이터·원본 참고 사진·영상·로컬 검증 로그를 포함하지 않습니다. 스크린샷은 예제 데이터로 생성합니다. Git 커밋의 작성자 표시명과 이메일도 공개되므로 자신의 공개 프로필이나 noreply 주소를 사용하세요.

## 공개 전 점검 범위와 한계

2026-10-22에 현재 소스와 도달 가능한 Git 이력의 비밀키·개인 경로·인증 파일·원본 미디어 포함 여부, Electron 경계와 라이선스 고지를 점검했습니다. 해당 정적 점검에서 공개를 막는 확정 문제는 발견하지 못했습니다. 정적 검토는 침투 테스트나 모든 취약점의 부재를 보증하지 않습니다.

의존성 취약점 조회인 `npm audit`는 npm 공식 보안 API의 네트워크 시간 초과로 결과를 받지 못했습니다. 취약점이 0개라는 뜻은 아닙니다. 네트워크가 가능한 환경에서 공개 시점에 다음 명령을 실행하고 결과를 검토하세요.

```sh
npm audit
npm audit --omit=dev
```

운영·개발 의존성을 구분해 영향과 호환성을 검토하고, 결과를 보지 않은 채 `npm audit fix --force`로 일괄 변경하지 마세요. 서명·공증된 설치 패키지 배포는 현재 제공 범위에 포함하지 않습니다.
